# 예시 수어 영상

여기에 넣은 영상은 모든 기기의 "TRY THIS SIGN" 카드에서 재생됩니다.

파일 이름 = 단어 (소문자, 공백은 `-`):
`hello.mp4`, `thank-you.mp4`, `yes.mp4`, `no.mp4`, `please.mp4`, `drink.mp4`, `happy.mp4`, `water.mp4`

- 3~4초, 상반신과 얼굴(표정·비수지 신호)이 모두 보이게
- 페이지의 "● 예시 영상 녹화" → "파일로 저장"으로 만든 파일을 그대로 올리면 됩니다
- 직접 촬영했거나 이용 허락을 받은 영상만 올려 주세요 (사전 사이트 영상은 저작권이 있어요)
